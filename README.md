# EstructurasDeDatosPython

Ejercicios variados con diferentes tipos de estructuras de datos implementadas en Python. El repositorio reúne prácticas y trabajos realizados durante la cursada de la carrera, cubriendo desde estructuras básicas de Python hasta árboles binarios y heaps.

## 📁 Estructura del proyecto

```
EstructurasDeDatosPython/
├── ArbolBinario/Heap/Array/     # Ejercicios de árboles binarios y heaps implementados con arrays
├── CastoloKits/                 # Ejercicios varios
├── EjercicioPractico/           # Ejercicio práctico integrador
├── EjerciciosPythonBasicos/     # Ejercicios de Python básico (fundamentos previos a estructuras de datos)
├── EstructurasList/             # Ejercicios sobre listas y estructuras basadas en listas
├── MamboretaEjercicioCSV/       # Ejercicio de manejo de archivos CSV
└── README.md
```

> Nota: algunas carpetas pueden contener sub-ejercicios adicionales; revisar cada directorio para más detalle.

## 🚀 Tecnologías

- **Lenguaje:** Python (100%)

## ⚙️ Requisitos

- Python 3.x instalado

## ▶️ Cómo usarlo

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Martinzanandrea/EstructurasDeDatosPython.git
   cd EstructurasDeDatosPython
   ```
2. Entrar a la carpeta del ejercicio que se quiera probar.
3. Ejecutar el script correspondiente:
   ```bash
   python nombre_del_archivo.py
   ```

## 🎯 Objetivo

Este repositorio tiene fines educativos: sirve como práctica y repaso de estructuras de datos (listas, árboles, heaps) y de manejo de archivos en Python.
